Android アプリ

21:30ロック

毎晩21:30になると、スマホのアプリが全部使えなくなります。パスワードか顔認証で解除するまでロックされたまま。電話・緊急通報・アラームはロック中も使えます。

アプリをダウンロード（Android）

わからなくなったら、このページのリンクを ChatGPT などの AI に貼って「設定を案内して」と送ってください。1つずつ案内してくれます。

AI に頼むときの言い方

このページのリンク（https://kazusora-maker.github.io/nightlock/）と一緒に送ってください。

入れたいとき　この手順で、Android スマホの設定を1つずつ案内して
止めたいとき　オフにして
また使いたいとき　オンにして
消したいとき　アンインストールしたい

準備するもの

  • Android 8.1 以降のスマホ（最近のスマホならほぼ大丈夫）
  • 紙とペン（パスワードをメモするため）
  • 約15分

入れ方

1. アプリをダウンロードする

  1. スマホの Chrome でこのページを開き、上の「アプリをダウンロード」を押す
  2. 「このファイルは有害な可能性があります」と出たら「ダウンロード」を押す

このページ以外から nightlock.apk をダウンロードしないでください。

2. インストールする

  1. ダウンロードが終わったら「開く」を押す（消えてしまったら、Chrome の右上「︙」→「ダウンロード」から nightlock.apk を押す）
  2. 「この提供元のアプリは許可されていません」と出たら「設定」→「この提供元のアプリを許可」をオンにして戻る
  3. 「インストール」を押す
  4. 「Play プロテクトによってブロックされました」「不明なアプリ」と出たら「詳細」→「インストールする」（または「このままインストール」）
  5. 「開く」を押す

3. アプリの中の5つの手順

アプリのいちばん上に「次にやること」が出ます。その通りに上から進めると、最後に「設定はすべて完了です」と出ます。

手順やること
1. パスワードを決める4文字以上。紙にメモして、スマホを使う人に見えない所にしまう
2. 他のアプリの上に表示を許可「設定を開く」→「21:30ロック」をオン → 戻る
3. 電池の最適化から外す「許可の画面を出す」→「許可」
4. ユーザー補助をオンにする「ユーザー補助を開く」→「インストール済みのアプリ」（または「ダウンロードしたアプリ」）→「21:30ロック」→ オン →「許可」
5. ためしにロックしてみる黒い画面が出たら、パスワードか顔認証で解除できるか確かめる

手順4でスイッチがグレーで押せないとき（Android 13 以降でよくあります）

  1. アプリの「アプリ情報を開く」を押す
  2. 右上の「︙」→「制限付き設定を許可」を押す
  3. アプリに戻って、もう一度「ユーザー補助を開く」から進める

4. 機種ごとの追加設定（必要な機種だけ）

  • Galaxy：設定 → バッテリー → バックグラウンドでの使用を制限 →「スリープしないアプリ」に「21:30ロック」を追加
  • Xiaomi / Redmi / POCO：設定 → アプリ → アプリを管理 → 21:30ロック で「自動起動」をオン、「バッテリーセーバー」を「制限なし」
  • OPPO / OnePlus：設定 → アプリ管理 → 21:30ロック → バッテリー使用量 で「バックグラウンドでの動作を許可」をオン
  • Pixel・AQUOS・Xperia・arrows：ふつうは不要

5. 後片付け

  1. 設定 → アプリ → Chrome →「不明なアプリのインストール」をオフに戻す
  2. ダウンロードした nightlock.apk は消してかまいません

使い方

  • 毎晩 21:30 になると、真っ黒な画面に「21:30です」と出て、ほかのアプリが使えなくなります
  • パスワードか顔認証で解除すると、次の日の 21:30 まで普通に使えます
  • ロック中でも電話に出る・緊急通報（110・119）・アラームを止めることはできます
  • パスワードを5回まちがえると、30秒待たないと入力できません

オン・オフのしかた

オフにする

  1. ロック中なら、先にパスワードか顔認証で解除する
  2. 「21:30ロック」を開く
  3. 上のほうの「21:30のロック：オン」のスイッチを押す
  4. パスワードを入れて「オフにする」を押す
  5. 「いまはオフです」と出れば完了

パスワードが必要なのは、スマホを使う本人が勝手にオフにできないようにするためです。

オンにする

  1. 「21:30ロック」を開き、「21:30のロック：オフ」のスイッチを押す（パスワード不要）
  2. 「オンにしました」と出れば完了。21:30 を過ぎてからオンにした日は、次の日の 21:30 からロックされます

困ったとき

21:30 になってもロックされない

アプリを開いて、5つの手順すべてにチェックが付いているか確認。付いていなければ「次にやること」をやり直す。機種ごとの追加設定もする。

顔認証のボタンがグレーで押せない

スマホ本体に顔が登録されていないか、その機種の顔認証がアプリから使えない種類です。パスワードで解除してください。

パスワードを忘れて、顔認証も通らない

スマホを「セーフモード」で起動すると、このアプリが止まります。多くの機種は「電源ボタン長押し →『電源を切る』を長押し →『セーフモード』」です（機種名＋「セーフモード」で検索）。セーフモードで「設定 → アプリ → 21:30ロック → アンインストール」で消し、再起動すると元に戻ります。

アプリを消したい

設定 → アプリ → 21:30ロック → アンインストール

安全性

  • インターネットにつながりません。スマホの中の情報が外に送られることはありません
  • 「ユーザー補助」では、いま前に出ているアプリの名前だけを見ています。画面の文字や入力した内容は読みません
  • パスワードは元に戻せない形にして保存しています
  • 顔認証はスマホ本体の仕組みを使います。顔の写真を保存することはありません

できないこと

  • ロックしていない時間なら、スマホの設定でユーザー補助をオフにしたりアプリを消したりすると止められます
  • セーフモードで起動すると止められます
  • 顔認証はスマホの持ち主の顔で解除できます

AI アシスタントへ（このページを読んだ AI の方へ）

あなたは、スマホに詳しくない人に「21:30ロック」の入れ方と使い方を案内する係です。

  1. 相手が何をしたいかで分ける。「オフにして」→「オン・オフのしかた」の「オフにする」だけ。「オンにして」→「オンにする」。「消したい」→「アプリを消したい」。「入れたい」「設定して」→「入れ方」の1から
  2. 入れ方を案内するときは、最初に「スマホのメーカーと機種名」「Android のバージョン」「スマホに顔認証を登録しているか」を聞く
  3. 1回に1ステップだけ案内し、「できました」と言われるまで次に進まない
  4. ボタンの名前は「」でくくり、その機種で実際に出る言葉で伝える。機種で違うときは候補を2〜3個あげる
  5. 専門用語は使わないか、一言で説明する。うまくいかないときは画面に何が出ているかを聞く
  6. あなたはスマホを直接操作できない。「オフにしました」とは言わず、本人がボタンを押すように案内する
  7. このページ以外からアプリをダウンロードさせない。開発者向けオプションやスマホの画面ロックを触らせない。パスワードを AI に教えさせない
